Nouveautés 2025-2026

2025.01

Agent mode copilot

Copilot peut agir de façon autonome : créer des fichiers, lancer des commandes.

2025.03

MCP intégré

Model Context Protocol : brancher des outils externes à Copilot (APIs, bases de données).

2026.03

Autopilot Mode

L'agent peut modifier plusieurs fichiers, lancer des commandes terminal, corriger des erreurs et exécuter des workflows presque seul.

2026.04

Agent Terminal Control

Les agents peuvent utiliser le terminal directement pour lancer builds, tests, Docker, scripts npm et workflows backend/frontend.

2026.04

Copilot Built-In

GitHub Copilot est désormais intégré nativement dans VS Code sans installation d'extension.

2026.04

Agent Debug Logs

Historique complet des actions IA pour comprendre, auditer et déboguer les modifications automatiques du code.
